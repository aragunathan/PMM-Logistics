Category: Acquisition
Save to: skills/acquisition/skill-09-google-ads-keyword-research.md

## When to Use
Run this skill before creating any Google Ads campaign for Ramco.
Keyword research must be completed before ad copy is written (Skill 10).
Wrong keywords = wasted budget at $150k+ ACV enterprise level.

## Inputs Required
- Google Keyword Planner (inside Google Ads account)
- SEMrush or Ahrefs for competitor gap analysis
- Regions in scope: Australia, Indonesia, Saudi Arabia
- Modules in scope: TMS (Transport Management), WMS (Warehouse Management)
- Conversion goal: Book a Demo

## The Core Principle
At $150k+ ACV you want LOW volume, HIGH intent, HIGH specificity keywords.
50 clicks/month at 8% conversion rate beats 5,000 clicks/month at 0.1%.

## HOW TO UPLOAD TO GOOGLE ADS
1. Go to Google Ads → Tools → Shared Library → Negative Keyword Lists
2. Click the + button to create a new list
3. Name it: "Ramco Logistics — Master Negatives"
4. Paste all terms above (one per line, no match type symbols needed
   for negative lists — Google treats all as broad match negatives)
5. Save the list
6. Go to each campaign → Settings → Negative Keywords →
   Apply Shared List → Select "Ramco Logistics — Master Negatives"
7. Apply to ALL campaigns before going live

## BID STRATEGY BY PHASE

### Phase 1 — Weeks 1 to 4: Manual CPC
Why: You have zero conversion data. Let Google gather data first.
How:
- Set bids manually based on Keyword Planner estimates
- Tier 1 keywords: bid 25% higher than Tier 2 keywords
- Start conservative — you can always increase bids
- Check Search Impression Share daily. If below 40%, raise bids.
- Do NOT enable any automated bidding yet

### Phase 2 — Weeks 5 to 12: Target CPA
Why: You now have conversion data (demos booked). Let Google optimize.
Trigger: Switch only after 30+ conversions recorded in Google Ads.
How:
- Calculate your starting Target CPA:
  If 20% of demos become pipeline opps, and each opp is worth $150k,
  then a $300 cost per demo is highly profitable. Start Target CPA at $300.
  Lower it gradually as volume allows.

### Phase 3 — Month 3 onwards: Maximize Conversions
Why: You now have HubSpot data showing which keywords drive revenue.
How:
- Pause keywords that generate demos but zero pipeline in HubSpot
- Increase budgets on campaigns producing pipeline
- Consider Target ROAS once you have revenue data flowing back

## HUBSPOT + GOOGLE ADS INTEGRATION

This is mandatory. Without this you cannot see which keywords
generate revenue — only which ones generate clicks.

### Setup Steps (do this before going live):

Step 1: Connect Google Ads to HubSpot
- In HubSpot: go to Marketing → Ads → Connect Account → Google Ads
- Authorize with the Google account that owns the Ads account
- Enable auto-tagging in Google Ads (Settings → Account Settings → Auto-tagging: ON)

Step 2: Set Up Conversion Tracking
- In Google Ads: go to Tools → Conversions → + New Conversion
- Select: Website
- Category: Submit Lead Form
- Name it: "Demo Booking"
- Install the conversion tag on the thank-you page after demo form submission
- OR import the HubSpot form submission goal directly into Google Ads

Step 3: Tag Contacts in HubSpot
Every contact created from a Google Ads click will automatically get:
- Original Source: Paid Search
- Original Source Drill-down 1: Google Ads
- Ad Campaign: [Campaign Name]
- Ad Group: [Ad Group Name]
- Keyword: [Keyword that triggered the click]

Step 4: Build This Report in HubSpot
- Go to Reports → Create Report → Contacts
- Group by: Original Source = Paid Search
- Filter by: Create Date = Last 90 days
- Add columns: Deal Stage, Deal Amount, Close Date
- This shows you which Google Ads traffic is becoming pipeline

Step 5: Monthly Keyword Revenue Review
- Export HubSpot contacts with Source = Paid Search
- Match to Google Ads keyword data by UTM parameters
- Pause keywords with 5+ demos and zero pipeline
- Increase bids on keywords with demos that became closed-won deals

## FAILURE MODES

Failure 1: Using Broad Match keywords
Result: Budget burns on irrelevant searches within 48 hours
Fix: Delete all broad match keywords. Use Exact and Phrase only.

Failure 2: Not uploading negative keywords before launch
Result: Clicks from job seekers, students, wrong industries on day one
Fix: Upload the master negative keyword list in Step 6 before any
campaign goes live. This is non-negotiable.

Failure 3: Sending all clicks to the homepage
Result: Conversion rate drops by 60-80% because visitors land on
a generic page with no clear next step
Fix: Every ad group must link to its specific module landing page.
TMS ads → TMS page. WMS ads → WMS page.

Failure 4: Not connecting Google Ads to HubSpot
Result: You see demos booked but cannot trace them to keywords
or campaigns. Budget optimization becomes guesswork.
Fix: Complete the HubSpot integration steps before going live.

Failure 5: Targeting all regions in one campaign
Result: Google's algorithm cannot optimize bidding properly.
Australian CPCs pollute Indonesian bid data and vice versa.
Fix: Always one campaign per region. Never combine.

Failure 6: Optimizing for clicks instead of conversions
Result: High traffic, cheap clicks, zero pipeline
Fix: Install conversion tracking on the demo booking confirmation
page on day one. Optimize only for demo conversions, not clicks.
