## Setup Checklist
### CRM
- [ ] Deal stages configured
- [ ] Custom properties created
- [ ] Lead routing rules set
- [ ] Sales sequences connected

### Marketing Hub
- [ ] Campaign UTM structure defined
- [ ] Forms connected to CRM
- [ ] Email templates loaded
- [ ] Workflows / automation built
- [ ] Lists segmented by persona and lifecycle stage

### Reporting
- [ ] Pipeline dashboard created
- [ ] Attribution report configured
- [ ] Weekly report scheduled

## UTM Naming Convention
`utm_source / utm_medium / utm_campaign / utm_content / utm_term`

Example: `linkedin / paid / q1-abm-launch / cio-ad-v1 / supply-chain`
