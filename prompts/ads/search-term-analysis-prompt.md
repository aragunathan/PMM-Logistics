# Prompt 2 — Analyze Search Term Report

**When to use:** Run this every Monday after your first week of campaigns going live — export the search term report from Google Ads and paste it into this prompt.

---

## Complete Prompt

I am running Google Ads for Ramco Logistics Software selling TMS
and WMS to enterprise 3PL companies.

Below is my search term report from the last 7 days.
These are the actual queries that triggered my ads.

[PASTE YOUR SEARCH TERM REPORT HERE]

Analyze this data and tell me:
1. Which search terms should be added as POSITIVE keywords
   (include recommended match type for each)
2. Which search terms should be added as NEGATIVE keywords
   (include which campaign to add them to)
3. Which search terms show the best buyer intent
4. Which ad groups have poor keyword-to-query alignment
5. Three specific actions to take this week to improve click quality

---

**How to get the search term report:** Google Ads → Keywords → Search Terms → Export
