# Prompt 3 — Monthly Keyword Audit

**When to use:** Run this at the end of every month using combined data from Google Ads dashboard and HubSpot Paid Search pipeline report.

---

## Complete Prompt

I am running Google Ads for Ramco Logistics Software.
Here is my monthly performance data:

Google Ads data (from Google Ads dashboard):
[PASTE: Campaign, Clicks, Conversions, Cost, CPC, CTR for each campaign]

HubSpot pipeline data (from HubSpot Paid Search report):
[PASTE: Keywords or campaigns that generated pipeline deals]

Based on this data:
1. Which campaigns should I increase budget on and by how much?
2. Which campaigns should I pause or reduce budget on?
3. Which keywords are generating demos but no pipeline? (pause these)
4. Which keywords are generating pipeline? (increase bids on these)
5. What is my actual cost per pipeline opportunity by campaign?
6. Three keyword additions or changes to make next month.

---

**How to get HubSpot data:** Reports → Create Report → Contacts → filter Original Source = Paid Search → add Deal Stage and Deal Amount columns
