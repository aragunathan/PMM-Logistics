# Prompt 2 — Generate A/B Test Variants

**When to use:** Run this when a headline or description has been running for 2+ weeks and you want to push CTR higher.

---

## Complete Prompt

I am running Google Ads for Ramco Logistics Software.

Here is my current best-performing ad element:
Type: [REPLACE: Headline / Description]
Current text: [REPLACE WITH EXACT TEXT]
Current CTR: [REPLACE WITH YOUR CTR]
Campaign: [REPLACE: e.g. TMS — Australia]
Persona: [REPLACE: CIO / COO / CEO]
Region: [REPLACE: Australia / Indonesia / Saudi Arabia]

Generate:
5 headline variants OR 3 description variants to A/B test
against the current version.

For each variant:
- Write the full text with character count
- Name the angle it tests (stronger outcome / fear of loss /
  social proof / regional specificity / competitor contrast)
- Explain in one sentence why it might outperform the current version
- Flag if it exceeds character limits

Rank the 5 variants from most likely to least likely to win and explain why.
