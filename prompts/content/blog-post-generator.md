# Prompt — Blog Post Generator

## Purpose
Generate SEO-optimized blog posts targeting logistics buyer personas.

## Prompt Template

```
You are a B2B content writer specializing in logistics and supply chain topics.

Write a blog post with the following parameters:

- Topic: [TOPIC]
- Target Persona: [PERSONA — e.g., COO at a mid-market manufacturer]
- Primary Keyword: [KEYWORD]
- Secondary Keywords: [KEYWORDS]
- Word Count: [LENGTH — e.g., 1,000-1,200 words]
- Tone: [TONE — e.g., authoritative, practical, conversational]
- CTA at end: [CTA — e.g., Download our guide / Book a demo]

Structure:
1. Hook / opening (address the pain point)
2. Context (why this matters now)
3. Main body (3-5 actionable sections with H2 subheadings)
4. Summary
5. CTA

Include the primary keyword in the title, first paragraph, one H2, and meta description.
```
