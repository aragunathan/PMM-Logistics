# Prompt — Case Study Template

## Purpose
Generate a structured customer case study to support sales and marketing.

## Prompt Template

```
You are a B2B case study writer. Write a customer success story using the following inputs:

- Customer Name / Industry: [NAME / INDUSTRY]
- Company Size: [SIZE]
- Challenge: [THE PROBLEM THEY FACED]
- Solution: [WHAT WAS IMPLEMENTED]
- Results: [QUANTIFIED OUTCOMES]
- Quote from Customer: [QUOTE if available]
- Tone: [TONE]

Structure the case study as:
1. Headline (result-led, e.g., "How [Company] Reduced Freight Costs by 22%")
2. Customer Overview (2-3 sentences)
3. The Challenge (1 paragraph)
4. The Solution (2-3 paragraphs)
5. The Results (bullet points with metrics)
6. Customer Quote (pull quote format)
7. Closing / CTA (1 sentence)
```
