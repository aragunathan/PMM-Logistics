# Prompt — Whitepaper Outline Generator

## Purpose
Generate a structured outline for a thought leadership whitepaper targeting logistics executives.

## Prompt Template

```
You are a B2B content strategist. Create a whitepaper outline on the following topic:

- Topic: [TOPIC]
- Target Audience: [AUDIENCE — e.g., VP of Supply Chain at enterprise manufacturers]
- Key Argument / Thesis: [MAIN POINT]
- Supporting Data Points: [DATA / STATS if available]
- Desired Length: [LENGTH — e.g., 10-15 pages]
- CTA at end: [CTA]

Provide:
1. Recommended title (3 options)
2. Executive summary outline
3. 5-7 section headings with 2-3 bullet points each describing content
4. Data / research suggestions per section
5. Recommended visual/chart ideas
6. CTA section outline
```
