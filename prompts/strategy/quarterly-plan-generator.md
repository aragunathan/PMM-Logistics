# Prompt 2 — Generate Quarterly Marketing Plan

Use at the start of each quarter to translate the annual plan into a detailed 13-week execution schedule.

---PROMPT START---
Read strategy/annual-plan-[YEAR].md and analytics/kpi-dashboard.md

Generate a detailed Q[NUMBER] marketing execution plan for Ramco Logistics.

Include:
1. Q[NUMBER] pipeline target (from annual plan allocation)
2. Channel priorities this quarter (ranked by expected pipeline impact)
3. Week-by-week content calendar (13 weeks — what gets published when)
4. Paid media plan for the quarter (campaigns live, budget by platform)
5. Events this quarter (from annual event calendar — include prep timeline)
6. Outbound campaign plan (which accounts, which sequence, which persona)
7. Experiments to run this quarter (from innovative programs section)
8. Key milestones: what must be done by Week 4, Week 8, Week 13
9. Owner for each activity (marketing / SDR / AE / agency)
10. Success criteria: what does a successful Q[NUMBER] look like?

Save to: campaigns/q[NUMBER]-[YEAR]-marketing-plan.md
---PROMPT END---
