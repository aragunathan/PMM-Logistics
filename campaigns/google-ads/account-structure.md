## Pre-Launch Setup Checklist

Complete every item before activating any campaign.

### Account Settings
- [ ] Set account timezone to match primary target region (use AEST for AU campaigns; set per campaign otherwise)
- [ ] Set account currency to USD for cross-region reporting consistency
- [ ] Enable auto-tagging (required for HubSpot integration)
- [ ] Link Google Ads account to Google Analytics 4 property
- [ ] Link Google Ads account to Google Search Console

### Campaign Settings (repeat for each campaign)
- [ ] Set correct location targeting — confirm exclusions (e.g., exclude residential suburbs if targeting enterprise hubs only)
- [ ] Set ad schedule per regional business hours (see each campaign above)
- [ ] Disable Search Partners and Display Network
- [ ] Set campaign-level negative keywords (see account-level list in Skill 09)
- [ ] Set device bid adjustments: +20% desktop, -10% mobile (enterprise buyers skew desktop)
- [ ] Apply shared budget or individual daily caps as defined above

### Ad Group Settings (repeat for each ad group)
- [ ] Upload all keywords with correct match types
- [ ] Apply ad group-level negatives where needed (e.g., negate "free" at ad group level if not already at account level)
- [ ] Create minimum 3 responsive search ads (RSA) per ad group — see Skill 10 for copy
- [ ] Set final URL to the correct landing page as defined in this document
- [ ] Add URL parameters: `?utm_source=google&utm_medium=cpc&utm_campaign=[campaign-name]&utm_content=[ad-group-name]`

### Negative Keywords (Account-Level — apply before launch)
- [ ] Add all negatives from Skill 09 to a shared negative keyword list
- [ ] Apply shared negative list to all 6 campaigns
- [ ] Negatives to add: free, open source, freeware, jobs, careers, salary, hiring, training, tutorial, course, certification, download, crack, torrent, small business, SMB, startup, DIY, spreadsheet, Excel, student, university, academic

### Extensions (add to all campaigns)
- [ ] Sitelink extensions: Add 4 sitelinks per campaign (e.g., "Request a Demo", "View TMS Features", "See Customer Stories", "Compare Plans")
- [ ] Callout extensions: Add 4 callouts (e.g., "Enterprise-Grade TMS", "Trusted by 3PLs in 50+ Countries", "HubSpot Integrated", "Dedicated Onboarding")
- [ ] Call extension: Add regional phone number if available
- [ ] Lead form extension: Enable for Solution Aware ad groups as secondary conversion path

## Conversion Tracking Setup

### Step 1: Install Google Ads Tag (Global Site Tag)

1. In Google Ads, go to **Tools & Settings → Measurement → Conversions**
2. Click **+ New conversion action → Website**
3. Configure:
   - Category: Submit lead form
   - Name: `Demo Request`
   - Value: Use the same value for each conversion (set to $500 as placeholder for pipeline reporting)
   - Count: One (count one conversion per click)
4. Copy the **Global Site Tag (gtag.js)** snippet
5. Paste the global tag into the `<head>` of every page on ramco.com — coordinate with web team
6. Add the **event snippet** to the thank-you/confirmation page that loads after a demo request is submitted:

```html
<!-- Google Ads Demo Request Conversion -->
<script>
  gtag('event', 'conversion', {
    'send_to': 'AW-XXXXXXXXX/XXXXXXXXXXXXXXXXXX',
    'value': 500.0,
    'currency': 'USD'
  });
</script>
```

7. Replace `AW-XXXXXXXXX/XXXXXXXXXXXXXXXXXX` with your actual Conversion ID and label from Google Ads
8. Verify tag is firing using **Google Tag Assistant** Chrome extension before going live

### Step 2: HubSpot Integration

**Method A — Native HubSpot–Google Ads Integration (Recommended)**

1. In HubSpot, go to **Marketing → Ads**
2. Click **Connect Account → Google Ads**
3. Authenticate with the Google account that owns the Ads account
4. Enable **Auto-tagging** (confirm it is already enabled in Google Ads account settings)
5. In HubSpot Ads settings, enable:
   - Lead syncing: ON
   - Ad interaction data on contact records: ON
   - Lifecycle stage auto-update from ad conversions: ON

**Method B — UTM Parameters + HubSpot Forms (Fallback)**

If native integration is unavailable, ensure all landing page URLs include UTM parameters:

```
?utm_source=google&utm_medium=cpc&utm_campaign=[AU-TMS]&utm_content=[ad-group-name]&utm_term={keyword}
```

HubSpot will capture UTM data automatically via its tracking code. Confirm the HubSpot tracking script is installed on all Ramco landing pages.

### Step 3: Verify Attribution in HubSpot

1. Submit a test form using a test Google Ads click (use Google Ads preview tool)
2. Check the resulting HubSpot contact record for:
   - Original source: Paid Search
   - Ad campaign name populated
   - Ad group name populated
   - Keyword populated (where match type allows)
3. Confirm the contact is routed to the correct HubSpot pipeline stage (e.g., "MQL — Paid Search")

### Step 4: Create HubSpot Reports for Google Ads

Set up the following HubSpot reports to monitor Google Ads performance:

| Report | Metric |
|--------|--------|
| Leads by campaign | Contacts created, grouped by `utm_campaign` |
| CPL by region | Cost per contact (requires manual cost input or Ads integration) |
| Demo requests by ad group | Form submissions grouped by `utm_content` |
| Pipeline influenced by Google Ads | Deals with original source = Paid Search |

## Notes for Media Buyer

- Start with **Maximize Conversions** bidding. Once each campaign reaches 30+ conversions/month, switch to **Target CPA** and set the target at 1.5x your current actual CPA.
- Review search term reports weekly for the first 30 days. Add irrelevant terms as negatives immediately.
- Pause ad groups with a CTR below 1% after 500+ impressions and rewrite ad copy.
- The Brand campaign (Campaign 6, Ad Group 11) should remain active at all times regardless of budget constraints — brand protection is non-negotiable.
- For Saudi Arabia, work with the content team to produce Arabic-language ad variants for Tier 2 ad groups within the first 60 days.
- Coordinate landing page creation with the web team before launch. Do not send paid traffic to the generic homepage.
