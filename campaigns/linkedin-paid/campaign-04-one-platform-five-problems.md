## Campaign Brief

**Objective:** Pre-sell CIO/VP IT persona on Ramco's integration simplicity, implementation realism, and data compliance posture — so that when an operations leader initiates an evaluation, IT is an accelerator rather than a blocker.

**Core pain targeted:** IT leaders at 3PLs are managing 3–5 point solutions (TMS, WMS, ERP connectors, custom-built tools, billing spreadsheets) that share no data model. Every new platform becomes an integration project. They've had bad implementations before. They're skeptical of vendor claims and want proof, documentation, and a realistic picture of what implementation actually requires from their team.

**Offer / CTA:**
- Content: "3PL Platform Evaluation Checklist for IT Teams" — 12 questions every IT leader should ask before shortlisting a vendor (LGF download)
- Demo: "30-Minute Technical Walkthrough — Built Around Your Stack" (Calendly / HubSpot Meetings)
- ABM Direct: Message Ad — API documentation + implementation resource guide, no sales pitch

**PPCO logic:**
- **Pain:** IT is the one holding together a patchwork of systems that were never designed to talk to each other
- **Proof:** Implementation methodology, reference architecture, specific integration examples (SAP, Oracle, custom ERP)
- **Change:** One platform with clean APIs, a structured implementation methodology, and an IT team that stops being middleware
- **Offer:** The 12-question checklist — positioned as a tool to evaluate any vendor, not a Ramco sales pitch

**Why this generates qualified pipeline:** The checklist offer is credibility-first — it helps IT leaders do their job, and it positions Ramco as a vendor that respects technical rigour. CIOs who download it have self-identified as actively evaluating platforms. The SDR follow-up can open with: "Did the checklist surface any gaps in what your current shortlist has answered?"
