## PHASE 2: STRATEGIC SUMMARY

### Business Model
**Sales-led Enterprise SaaS** — No self-serve. Every deal requires multi-stakeholder consensus (CIO + COO + CEO) and a 180-day cycle. Marketing's job is to generate pipeline, pre-build value, and accelerate deal velocity — not to close.

### Core Growth Motion
**ABM + Reference-Led Sales.**
1. Build named account lists (Skill 01)
2. Run outbound sequences by persona/region (Skills 02, 03, 04)
3. Deploy proof points (VISY case study, ROI calculator) before price enters the conversation
4. Close with peer references and executive briefings

### Primary Bottlenecks (ranked by pipeline impact)

| Rank | Bottleneck | Impact | Fix |
|------|-----------|--------|-----|
| 1 | Email open rate at 5% | All outbound crippled | SPF/DKIM/DMARC fix + subject line rewrite |
| 2 | VISY case study unpublished | No primary proof point | Publish by EOQ2 |
| 3 | Win rate 20% (price is #1 loss reason) | Revenue gap | ROI calculator + cost-of-inaction content before demo |
| 4 | Pipeline volume insufficient for $8M ARR | Revenue gap | Triple outbound volume OR increase ACV |
| 5 | No formal partner co-marketing programme | Missing low-cost channel | Formalise HERE, Macship, WHG by Q3 |

### Strategic Priorities (2026)

**Priority 1 — Fix the Pipe Before Filling It**
Before adding new channels, fix what is broken. Email deliverability at 5% open rate means the outbound engine is not running. This is a technical fix (SPF/DKIM/DMARC), not a content problem. Resolve in Week 1.

**Priority 2 — Publish VISY and Make It Work in Every Channel**
VISY Logistics is Ramco's best asset and it is sitting unused. A fully produced case study (3 personas × 3 formats = 9 assets) makes every other channel — email nurture, LinkedIn ads, Google Ads retargeting, sales decks — immediately more effective.

**Priority 3 — Pre-empt Price with ROI Data**
The #1 loss reason is price. Price is a perception problem, not a product problem — because Ramco wins on features. Deploy an ROI calculator for the Ops persona by Q2. Build business case templates for the CEO persona. Change the sequence: value before demo, ROI before commercial.

**Priority 4 — Australia First, Depth Over Breadth**
$60K of the $100K budget goes to Australia. One market, executed well, generates the playbook and the references that unlock Indonesia and Philippines in H2.

**Priority 5 — TMS Repositioning as the 2026 Campaign Anchor**
The new TMS platform launch is the single most important campaign event of the year. Every channel (ads, email, events, LinkedIn, PR) should reference this launch. It creates urgency (upgrade cycle), proof (new capabilities), and news (outreach hook).

## DECISION TREES

### Channel Selection Logic

```
NEW LEAD / ACCOUNT IDENTIFIED:

Is the account on the T1 TAL?
├── YES → SDR LinkedIn outreach (Skill 02) + Email nurture (Skill 04) simultaneously
│         → If no response in 14 days → LinkedIn message 2 (Skill 02, Step 2)
│         → If no response in 30 days → Add to LinkedIn retargeting audience (Skill 11)
└── NO → Is the company an ICP match (3PL, $100M+ revenue)?
         ├── YES → Add to T2 TAL → LinkedIn Persona Layer ad targeting (Skill 07)
         │         → If engages with content → Promote to T1 → SDR outreach
         └── NO → Exclude from all paid targeting; organic only

INBOUND LEAD (from Google Ads, SEO, event):
Is the lead ICP-matched (title + company)?
├── YES → MQL in HubSpot → Persona-specific nurture sequence (Skill 04)
│         → SDR LinkedIn connection request within 24 hours (Skill 02)
└── NO → Subscriber status only; add to broad nurture; do not SDR-follow
```

### Skill Prioritisation Logic (when time-constrained)

```
RULE 1: Pipeline output before brand output.
  If choosing between a case study and a battlecard → battlecard first (deals in pipeline today)
  If choosing between a whitepaper and an email sequence fix → fix the sequence

RULE 2: Fix before build.
  If email open rate < 20% → fix deliverability before building new nurture content
  If LinkedIn connection rate < 20% → fix outreach messages before scaling volume

RULE 3: Australia before other regions.
  All new content, campaigns, and sequences start in AU format.
  Localise for ID, SA, PH only after AU version is tested and performing.

RULE 4: Proof before promotion.
  No paid ad campaign launches without a case study or ROI data point in the landing page.
  No SDR sequence launches without persona-specific proof point in email 2.
```

### ENTERPRISE LAYER — Multi-Stakeholder Flow

```
ACCOUNT ENTRY POINT:
Most deals start with one persona. The entry persona determines the initial sequence.

COO entry (most common):
→ Ops sequence (Skill 04, Track 2) → ROI data + VISY ops case study
→ After demo: deploy CEO one-pager for internal champion to use with board
→ After proposal: CIO technical pack (architecture guide, security docs)

CIO entry:
→ IT sequence (Skill 04, Track 1) → Integration architecture guide + implementation methodology
→ After connection: invite to roundtable with peer CIOs (Skill 05)
→ After proposal: CEO one-pager for sign-off conversation

CEO entry (rare):
→ Executive sequence — short, outcome-only → Peer CEO reference call offer
→ Route immediately to senior AE + country head

MULTI-THREADING RULE:
Once one persona is engaged, SDR must identify and connect with the other two within 30 days.
A deal with only one engaged stakeholder is 3x more likely to stall.
```
